# FORTRESS ガレージ

制作した PNG を重ね、全状態を再生するローカルの動作試験ツール。
ゲーム本体から独立しており、対戦の物理や通信は変更しない。

```sh
pnpm assets:lab
# http://127.0.0.1:4178
pnpm assets:test
pnpm assets:test:browser
pnpm assets:validate assets/workbench/baseline-v2
```

待機、移動、発射、被弾、低 HP、落下、着地、大破、残骸を選べる。
再生、停止、先頭、60 fps の 1 フレーム送り、スクラブ、速度変更に対応する。
各状態のコマボタンで、絵が切り替わる正確な時刻へ移動して停止できる。
初期状態は検証用の繰り返し再生。単発の動作も終端から先頭へ戻る。
「繰り返し確認する」を外すと終端で停止し、大破は残骸の姿勢を保持する。
再生ボタンを再度押すと先頭から再生する。
動きを減らす環境設定では停止状態で開く。

8 武器、主色とアクセント色、メガネ、スカーフ、HP、左右、仰角、傾斜、拡大率を変えて比較する。
接続点と顔の保護領域、パイロット単体も表示できる。
ガレージの描画は manifest の frame と duration を読む。
足回り、反動、上下動、煙、砲弾は独立して合成する。

「全アニメーションを検査」は次を確認し、JSON で保存する。

- 各 clip のフレーム境界と低 HP、大破、残骸の状態遷移。
- 9 状態 × 左右 × 2 仰角で、各 clip の境界直前・境界・代表時刻・終了時刻を実描画（現 pack は 368 通り）。
- 8 武器の 10〜90 度、反動 0〜3 px における全16ポーズの目と共通保護領域との重なり。
- キャノピー前面と顔の保護領域との重なり。
- 全コマの縦横比、共通倍率、頭・首の接続点と目の領域。

今回の問題と次回生成時の規則は [修正記録](../../docs/design/15-animation-feedback.md) に集約する。

描画検査は読み込み、例外、空の描画、保護領域を対象にする。
顔の解剖学、演技、全ポーズの搭乗感、絵の魅力は目視でも確認する。装備と目の重なりは自動検査と目視を併用する。
検査は現在の試作 pack を対象とし、未制作の別種や足回りまで検証済みとは扱わない。
検査結果の humanReview は常に pending とし、review.json を自動生成しない。

試射の飛行軌跡は演出確認用であり、sim の弾道ではない。
連射の発射間隔、爆発の 70 / 190 / 410 / 590 ms の境界を確認するが、武器固有の貫通処理や地形削除はゲームへの統合時に検証する。
ゲーム内での実寸可読性と本体の物理サイズとの対応も未承認である。

assets/workbench/baseline-v2 を初期 pack として読む。
別種や別足回りを足す際は、描画器の選択 UI と試験ケースも追加する。
サーバーは localhost のみで待ち受け、ツールと workbench の画像と JSON 以外を公開しない。
ポートを変える場合は ASSET_LAB_PORT を指定する。


最新パックは29アセット・74フレーム。41項目の検査には、PNG実画素を使ったメガネの接触と目の非遮蔽、透過面、腰の遮蔽、履帯支持と接地、砲口、VFX消散・異色片混入、ガラスの枠外チェックも含む。Node側のvalidateと同じ関数を使用する。

`pnpm assets:export:v2` は生成元から機械的に再出力する（sharpが必要）。`pnpm assets:capture` は起動中のこのツールから比較画像と検査JSONを `assets/previews/asset-lab-v2/` へ保存する。保存画像は実レンダラーの結果であり、別の見本用描画ではない。
