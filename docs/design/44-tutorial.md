# 44. チュートリアル

初めて遊ぶ人に、戦車の基本の操作を一つずつ促して覚えてもらう。
盤面はターゲットチャレンジ（37章）の仕組みを使い、画面の下にメッセージボックスを重ねて「XXX すると YYY できます。XXX してみてください。」の形で次の操作を案内する。
物理、対戦用 engine、サーバー、通信プロトコルは変えない。

## 44.1 入口と戻り先

- 初回は、タイトル画面の「はじめる」でチュートリアルへ入り、終えると出撃準備（ロビー）へ進む。
- プラクティスのモード選択の先頭に「チュートリアル」を置き、いつでもやり直せる。
  終えるとプラクティスのモード選択へ戻る。
- 招待リンク（`?room=`）で開いたときはタイトル画面を通らないので、チュートリアルへ入らない。

初回の判定は次のとおり。

- 済みの印（`fortress.tutorial.v1`）、チャレンジの記録（`fortress.practice.v1`）、名前を入れたプロフィール（`fortress.profile.v1`）のどれも無ければ初回とする。
  名前かチャレンジの記録がある人は今までに遊んだ人とみなし、導入前から遊んでいる人には出さない。
- プロフィールがあるだけでは初回でないと言えない。
  `loadProfile` は最初の読み込みで playerId を残すために、名前の空の既定値を保存するからである。
  プロフィールの有無で判定すると、タイトルで離れた人は次に来たとき案内されない。
- 招待リンクから先に対戦した人は、名前を入れているので、あとで通常の入口から来ても案内しない。
- チュートリアルに入った時点で `fortress.tutorial.v1` を保存する。
  途中でメニューからやめても、次から強制しない。
- 保存できない環境では覚えられないので、起動のたびに初回として扱う。
  同じ画面の中では、タイトルへ戻って「はじめる」を押し直しても二度は案内しない。

画面切り替えのシャッターは対戦と同じ battle の向き（中央から開く）を使う。
ブラウザの戻るはプレイ中のメニューを開く（37.4 と同じ）。

## 44.2 盤面とメッセージボックス

- 地形は400×225セルの平らな床（y=180 から下）。
  開始位置は x=100、装備は標準砲と三連弾。
- 的ははじめは無く、手順に合わせて出す（44.3）。
  風もはじめは0で、風の手順から右向き6（チャレンジの「風に乗せて」と同じ）にする。
  手順に入ったときの的と風は手順から決まる（`tutorialSetup`）ので、場外に落ちて盤面を作り直したときもかけ直せる。
- 開始時はターゲットチャレンジと同じ俯瞰から自機へ戻り、操作を受け付けられるようになってから案内を出す。
- 盤面は、的をすべて壊しても弾を使い切っても終えない（ストアの `endless`）。
  床は厚さ45セルあり、歩いても場外に出ない。
  記録は残さない。
  自分の足元を撃ち続けて場外に落ちたときは、「弾切れ、または戦車が場外に落ちました。」と「再挑戦」を出し、盤面だけを作り直して同じ手順から続ける。
- 操作盤は対戦と同じもの（37.1）を使う。角度メーターの下に風のメーター、武器の上にアイテムの段を出し、▲▼◀▶ と発射のボタンはタッチ端末だけに出す。
  当初はチャレンジの古い操作盤のままで、風のメーターもアイテムの段も無かった。2026-10-05 のユーザー指示で対戦にそろえた。
- アイテムはチュートリアルでだけ選んで撃てる（ストアの `items`）。
  計算は対戦と同じ `simulateCombatWithItem` で行う。
  アイテムの段は、使い切って先へ進めなくならないよう、アイテムの手順の間だけ押せる。
- 上の中央（チャレンジでは面の名前と残りの数を出す場所）は、ふだん何も出さない。
  制限時間の手順だけ、対戦と同じ時計を出す。
  「チュートリアル 的 1」と出していたが、何を表すのか分かりにくいという所見を受けて 2026-10-05 に外した。
- メッセージボックスは画面の上の中央に重ね、左上の設定と全画面のボタン、右上の全体図を避ける。
  全体図の幅（220px、150px、100px）に合わせて左右に同じだけ空ける。
  制限時間の手順では、時計の下へずらす。
  縦持ちでは左右の間が狭いので、上のボタンと全体図の下の段に出す。
  横持ちのスマートフォンは盤面が低いので、本文とボタンを横に並べて高さを抑え、自機にかからないようにする。
  盤面と操作盤の間には行を取らない。
- 文字はすべて 16px にする。
  画面の書体（DotGothic16）は 16px のドットで描かれていて、文字の平滑化を切っているので、12px や 14px では点が間引かれて潰れる。
  当初は本文を 14px、見出しを 12px にしていて、文字が潰れて読みにくいという所見があった。
- 非モーダルで、案内を出している間も操作を止めない。
  操作を促す手順にはボタンを置かず、促した操作でだけ進める。Space も発射にだけ効く。
  「次へ」で進む説明の手順は射撃操作を止め、ボタンにフォーカスを移す。
  このとき Space と Enter はボタンの押下にだけ効く。
- 「スキップ」は置かない（2026-10-05 のユーザー指示）。
  途中でやめるときは、プレイ中のメニュー（Esc、設定ボタン）の「チュートリアルをやめる」を使う。
  メニューには「チュートリアルに戻る」も置く。
- 促している操作の部品を黄色の枠で点滅させる。
  角度は角度メーター、移動は残り移動のバー、タッチ端末ではそれぞれの ▲▼ と ◀▶ も点滅させる。
  武器のボタン、パワーの目盛り、発射のボタン、風のメーター、時計、アイテムのボタンも、その手順で点滅させる。
  動きを減らす設定では点滅しない。
- タッチ端末かどうかは対戦の操作盤と同じ判定（`useTouchControls`）で決め、文言を切り替える。
  デスクトップではキーを書き、タッチ端末では画面のボタンを書く。

## 44.3 手順

| 手順 | 促す操作と伝えること | 進む条件 |
|---|---|---|
| 1 導入 | 案内に沿って操作すると次へ進むこと | 「次へ」 |
| 2 角度 | ↑↓ か ▲▼ | 上げると下げるの両方をする |
| 3 移動 | ←→ か ◀▶。向きも変わる。1回撃つまでに歩ける歩数に限りがある | 左と右の両方へ動かす（歩数が尽きても向きが変われば数える） |
| 4 武器 | Q か E、または武器ボタン（縦持ちでは右下に無いので位置は書かない） | 選んだ武器が変わる |
| 5 発射 | Space か発射ボタンの長押し | 1発撃ち、再生が終わって次を撃てるようになる |
| 6 目安の線 | パワーの目盛りを押すと目安の線を引ける。いま撃ったパワーのあたりを押させる | 目盛りを押して線を引く |
| 7 的を壊す | ここで初めて右に的（x=170）を出す。目安の線を目印に角度とパワーを調整する。左右で向きが変わること、ドラッグで見回せることも伝える | 的が壊れ、再生が終わる |
| 8 風 | 風を吹かせ、風のメーターで向きと強さが分かることを伝える | 風の中で1発撃ち、再生が終わる |
| 9 制限時間 | 上の中央に対戦と同じ時計を出し、20秒（`TURN_LIMIT`）を数える。時間内に撃たないと撃たずに手番が終わること | 「次へ」 |
| 10 アイテム | 新しい的（x=240）を出し、アイテムの段を押せるようにする。ダブルシュートとテレポートの効果、1試合に1回ずつ使えること | アイテムを使って撃ち、再生が終わる |
| 11 完了 | プラクティスで復習できることを伝える | 「出撃準備へ進む」か「プラクティスへ戻る」 |

- 判定は純関数（`observeTutorial`）が、ストアの状態が1回変わるたびに、前の状態と今の状態を比べて行う。
  上と下、左と右の両方をしたかは、その手順の間にした向きを集めて見る。
  描画ごとに見ると、続けて変わった状態を取りこぼして片方の向きを数え損ねるので、ストアを直接購読する。
  促していない操作をしても進まない。
- 発射は的を出す前に試させる。
  的を出してから撃たせると、目安の線を引く前に当たってしまうことがある。
  また、どこへ撃ってもよい1発目で長押しの感覚をつかんでから、目安の線を引かせる。
- 目安の線は盤面の状態に残らない（パワーの目盛りの部品の中だけにある）ので、目盛りが線を引いたことを知らせ（`onPowerMemo`）、画面が次へ進める。
  目安の線はポインターでしか引けないので、キーボードだけの人はこの手順で止まる。マウスかタッチで目盛りを押す必要がある。
- 移動の手順では左へ歩くので、的の手順に入ったとき左を向いていることが多い。
  的の手順で、左右の操作で向きが変わることを伝える。
  伝えないと、左を向いたまま的の反対へ撃ち続けてしまう。
- アイテムの手順で新しい的を出すのは、ダブルシュートが、生きた的が無いと2発目を撃たない（42.2）からである。
  的の手順の的はもう壊れているので、新しい的が無いと2発目を見せられない。
- 制限時間の時計は0になっても失敗にせず、数え直す。
  時計は対戦と同じく残り5秒から明滅し、1秒ごとに音を鳴らす。

的の位置は、標準砲ならどの角度でもパワー42〜50前後で当たる距離にした。解法（開始位置、標準砲、46度、パワー45）を `apps/client/test/fixtures/challenge-solutions.ts` に置き、手順の判定と合わせてテストする。
手順の数、文言、進む条件、風の強さは初期値で、初めての人に遊んでもらって調整する（TBD-tutorial-1）。

## 44.4 テスト

- `apps/client/test/tutorial.test.ts`：角度と移動は両方の向きをしたときだけ進むこと、歩数が尽きても向きで数えること、説明の手順と目安の線は盤面の状態では進まないこと、的は的当ての手順で初めて出ること、風の中で撃つと進むこと、アイテムの手順ではダブルシュートが2発目まで撃つこと、盤面の準備を手順からかけ直せること、外し続けても的を壊しても盤面が終わらないこと。
- `apps/client/test/challenge-store.test.ts`：的の追加、風の変更、アイテムの選択（チャレンジでは選べない）、ダブルシュートとテレポート、`endless`。
- `apps/client/test/tutorialSeen.test.ts`：初回の判定と保存、保存できない環境。
- `apps/e2e/world-tests/tutorial.spec.ts`：初回の「はじめる」から完了して出撃準備へ出ること、2回目はロビーへ直行すること、操作の手順にボタンが無いこと、片方の向きだけでは進まないこと、目安の線、風のメーター、時計、アイテム、メニューからの退出（初回は出撃準備、プラクティスからはプラクティス）、タッチ端末の文言。
- 既存の e2e は、新しいブラウザ文脈でも「はじめる」でロビーへ進むよう、各 config の `storageState` に済みの印を入れる（`apps/e2e/tutorialSeen.ts`）。チュートリアルの spec だけ空の状態で上書きする。
