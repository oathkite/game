# シンプルなドットテーマへの方針変更

2026-09-13のユーザー指示を最優先とする。画像によるグラフィックアップデートを取り下げ、以前の緑と黒のドットテーマへ戻す。制作の重点はゲーム性、操作感、対戦の安定性に置く。

## 表現

- 黒い背景、緑のUI、白い地形、ドットフォントを基準とする。旧 `styles.css` と `08-visual-direction.md` を参照する。
- チーム識別の色は維持する。キャラクター、弾、爆発は読み取りやすい簡素なドット描画とする。
- 生成画像の背景、コックピット、ロゴ、肖像、地形テクスチャ、START画像を通常画面の必須素材にしない。名称は変更する。新名称は未定とし、旧名称は制作記録としてのみ残す。タイトルは新名称決定後に文字で表す。
- 装飾目的の動画・アニメーション制作は終了する。落下、弾の飛翔、着弾、手番のカメラ移動など、状態の把握に必要な動きは維持する。
- BGM・効果音も新しいドットテーマの世界観に合わせて再制作する。既存音源は発表用の制作記録として保存する。

## 維持する機能

- 最大8人・自由なチーム編成、リアルタイム移動、部屋、クイック参加、招待、観戦、再接続、リザルト。
- 可変サイズの破壊可能マップ、橋や足場、落下アニメーション。見た目の変更を理由に当たり判定や保存済みマップ版を変更しない。
- 調整済みのカメラ速度・慣性・イージング・表示倍率、手番切替、開始時のマップ紹介。
- WASD／矢印で移動と角度、Spaceで射撃、Q/Eで武器切替、Tabで参加キャラクターへカメラ移動。
- キーボードのない端末のコンパクトな十字キー。長い100段階のパワーメーター、地面と射出方向を示す円形角度計。
- 入力フォーカス、画面回転、発射位置など、これまでの不具合修正。

## 実装順序と完了条件

1. 現在の通常起動・通信・状態管理を維持して、全シーンを旧配色と単純な枠・文字へ変更する。旧Appへの入口変更だけで済ませない。
2. 地形は既存の衝突maskを単色描画し、キャラクター・弾・爆発の画像依存を置き換える。表示と衝突が一致し、橋の下や下段の足場が読めることを確認する。
3. PCとモバイルで視認性と操作領域を確認し、射撃・落下・カメラ・武器切替を検証する。
4. オンライン複数人の移動・射撃・再接続・結果を既存テストで確認する。通常起動で不要な生成画像を読み込まないことを確認する。

旧テーマへ戻すための通信やゲームルールの巻き戻しは行わない。過去の素材は履歴として保存し、使わなくなった表示コード・importは置換時に整理する。

## 旧方針との関係

27章・29章・35章などの画像素材とコックピット原案への一致は、今後の完了条件から外す。既存のUI原案の最終承認待ちはこの方針変更によって解消する。実機検証や公開環境の確認は別途残る。

この文書は方針の決定を記録したものであり、テーマの切替実装が完了したことを示さない。本番公開・mainへの統合は引き続き別の明示的指示で行う。
