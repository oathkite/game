## 従来設計と制作資料

KEROPOD は、自分のキャラクターが共通キャノピーのマシンに乗り、風と地形を読んで一発を競う 2D ドット絵の対戦ゲームである。
2026-09-09 改訂では、承認された横視点のマシンとカエルを基準に世界観と UI を再定義する。

## 設計と現在の実装

本書の世界観と新 UI は制作目標であり、実装済みを意味しない。
現在のアプリには矩形で描く機体と従来の画面が残る。
画像プレビューは確認用であり、完成 atlas ではない。
制作中の基準素材は [baseline-v2](../../assets/workbench/baseline-v2/README.md)、合成と再生は [ガレージ動作試験台](../../tools/asset-lab/README.md) で確認する。

| 区分 | 内容 |
|---|---|
| 維持する契約 | 1 対 1、既存 8 マップと 8 武器、ターン、風、地形破壊、決定論、通信と再接続 |
| 今回の制作目標 | 搭乗者が見える固定本体、真横のドット絵、ガレージを中心にした新 UI |
| 将来の拡張 | キャラクター種とスキン、足回り、武器、外見カスタマイズ |
| 未決定 | 実寸と倍率、外見の販売方式、課金用アカウント、大破後の退場、追加素材 |

種族は固定せず、将来の追加余地を残す。現在の黄色いカエル＋オレンジスカーフ＋メガネは本人専用とし、一般用の初期アバターは別途制作する。
白い喉と腹へ目や顔を描かない。
スキンや足回りを増やしても、本体の形状と寸法は変えない。
