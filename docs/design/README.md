# 設計ドキュメント

ブラウザで遊ぶ 1 対 1 のターン制砲撃対戦ゲームの設計をまとめる。
題材はポトリス（Fortress）で、その遊びを「風を読み、角度とパワーを決めて撃ち、直撃か地形破壊によるリングアウトで勝つ」という核まで絞る。

## 設計の前提

- 一番守るものは「うまいショットが決まった瞬間」の気持ちよさである。数値や UI の判断は、すべてこの一点に寄せる。
- 最初の版は遊びを最小にする。機体は 1 種類、アイテムなし、マップは固定 3 枚、1 対 1。面白さが確認できてから要素を足す。
- ブラウザで動き、PC とモバイルの両方で遊べる。パワーを決める長押しの体験は、両者で差をつけない。
- 画面は黒地に緑の UI、白い地形、色付きの戦車で、すべて同じ大きさの正方形（セル）で描く。セルは見た目の単位であると同時に、地形と物理の単位でもある。
- 物理はサーバーとクライアントが同じコードを実行し、同じ入力から同じ結果を得る。サーバーは結果の確定だけを担い、弾道の座標列は送らない。
