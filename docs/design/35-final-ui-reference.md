# 最終ゲームUIの比較基準

[承認済み原案](references/battle-hud-approved.png)は、ユーザーと調整した
`desktop-refined-v4.png`の原本を変更せず保存したもの。
これまではGit対象外のoutputにのみ置かれていた。

## 原案から維持するもの

- 空と地形を広く見せる戦場、上部の個別参加者カード、中央の時間表示。
- 濃紺のコックピットパネル。背景上の文字は面・縁・影で読めるようにする。
- 下部の自機情報、金属の縁がある円形角度計、長いパワーメーター、2武器。
- 角度計は地面の傾斜と射出方向を区別する。
- パワーは100等分し、10刻みを強調。値と指針を即時に同期する。

## 原案より後のユーザー指定

- チームは色で表現し、原案の図形記号を復活させない。
- 弾の軌跡は表示しない。
- DesktopはWASD/矢印で移動と角度、Spaceで発射、Q/Eで武器、Tabで機体巡回。
- キーボードのない端末では左側にコンパクトな十字キーを表示する。
- ゲーム画面へ説明文を常設しない。
- 地形は生成した画像と一致する破壊可能maskを使用する。
- 標準カメラ倍率は75%。移動2.8倍、慣性1000ms。

## 現時点の差と確認対象

機能の実装・テスト合格を原案との見た目の一致として扱わない。
現在のパネルは平面的で、原案の個々の計器を組み込んだ質感に届いていない。
Desktopの余白と計器比率、8人カード、縮小時のメーターの読み取りやすさを比較する。
ミニマップと機体ラベルの重なり、モバイルで戦場を見られる高さも確認する。

承認済みの機体・パイロット素材を維持し、原案内の仮機体へ戻さない。
最終の見た目の承認は未記録。実機での操作確認はブラウザ自動試験とは分ける。
