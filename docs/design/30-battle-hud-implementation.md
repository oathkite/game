# ゲームHUD 第一実装

2026-09-10。ユーザー承認の `desktop-refined-v4.png` を基に、worldプレビューのプラクティスとオンライン対戦へ共通HUDを実装。

## 表示

- 上部：参加者名とチーム色のHPバー、手番枠、残り時間、風、設定。
  - 2026-09-13 に上部の帯を外したとき風の表示も外れた。2026-09-27 に風のメーターとして、下部の操作盤の角度メーターの真下へ戻した（8.5）。
- 下部：自機（ローカル対戦は手番機体）のHP数値と移動残量、円形角度計、長いパワーメーター、装備アイコン。
- チーム記号を削除。一覧・機体ラベル・ミニマップで共通の8色パレットを使用。
- 角度計はSVG。水平基準と地面の傾斜、射出方向、地面に対する仰角を表示する。射出方向はsimのfireAngleを直接使用し、左右反転も同じ基準で扱う。自分の射撃の再生中は、撃った位置と向きで描く。確定した位置は再生が終わるまで手番の初めのままなので、それを使うと向き直して撃った再生のあいだだけ逆を向く。
- パワーは101本の境界線による100等分。0〜100の10刻みを強調。値とカーソルは操作値へ直接同期し、遅延する補間は入れない。数値をSVGの横方向縮小から分離してモバイルの文字幅を保つ。
- SVG武器アイコンは武器IDに対応。スロット順を変えても形は同じ。
- 武器のボタンの上の段に、アイテム（42章）のアイコンだけの低いボタンを武器と同じ幅で並べる（2026-10-02）。武器のボタンにはQ/Eの文字を出さない。キーの操作は残す。
- 背景とタンクは既存の生成済みアセットを使用。今回新たなラスター素材の生成は不要。

## 操作

デスクトップはA/Dまたは左右矢印で移動、W/Sまたは上下矢印で角度、Space長押し→解放で発射、Q/Eで装備切替。Tabで生存中の参加機体へ順番にカメラを移す（手番機体の次から開始、末尾で先頭へ）。設定内では通常のTab移動を維持する。
説明は設定画面へ集約。戦場には説明文を常駐させない。

ブラウザには物理キーボードの接続有無を確実に取得する共通APIがない。
初期表示はpointer:coarseで判断し、実際のゲーム用キー入力を検出すると画面上の移動・角度・発射ボタンを隠す。タッチ操作は44px以上を確保する。ただし36章の「コンパクトな十字キー」で十字キーは32pxになっており、E2Eは十字キー32px、発射44pxを下限として検査している（TBD-31）。

タッチの操作盤は、スマートフォンの向きで並びを変える（2026-10-02）。

- 横持ち（高さ499px以下）：発射のボタンを右端の列に置き、操作盤の高さいっぱいに広げる。その左に武器とアイテム、さらに左にパワーと残り移動を置く。パワーと残り移動の幅はその分だけ縮む。
- 縦持ち（幅599px以下）：操作盤を112pxから216pxに高くする。上の段に十字キー、角度とその下の風、武器とアイテム、発射を並べ、発射は残りの幅に広げる。パワーと残り移動は、それぞれ盤の全幅の段に置く。幅が狭いと目盛りが読みにくいためである。練習の画面は地図の高さを `touchConsoleHeight` で同じ条件から求める。
- どちらの向きでも、武器とアイテムの段の合計の高さを発射のボタンの高さに揃える。アイテムの段は28pxに固め、武器のボタンが残りを埋める。アイテムが無い画面では武器のボタンが発射と同じ高さになる。
- タブレットとデスクトップの並びは変えない。

オンラインの充填も既存PowerGaugeを使用。メニュー、失焦、非表示化、手番終了で充填を破棄する。移動と充填の多重入力を防ぐ。
オンラインではサーバーが確定した現在の風を表示。下部は自機の角度・HP・装備を保持する。相手の仰角はリアルタイム配信契約には含まれない。
相手の手番と相手の射撃の再生中も、角度（W/S、上下のボタン）と装備（Q/E、装備のボタン）と向き（A/D、左右のボタン）は変えられ、次の自分の手番に引き継ぐ。
当初は相手手番の入力をすべて無効にしていたが、2026-10-01 のユーザー指示で、37.6 の CPU 戦と同じ規則にそろえた。
向きは 2026-10-02 のユーザー指示で加えた。
相手の手番の左右は向きだけを変え、位置は動かさない。押し続けても繰り返さない。
移動と発射は自分の手番だけ。自分の射撃の再生中、開幕と手番順の演出中、対戦の終了後、観戦中、設定メニューと退出の確認の間は、角度と装備と向きも変えない。
変えた角度と装備と向きは自分の画面の自機にだけ出し、発射まで送らない（22.5）。
サーバーは手番の初めの向きを右にするので、準備した向きは自分の手番で動くまで予測の向きとして使い、`turn.fire` の `facing` で送る。
相手の手番に向きを変えなければ、前の自分の手番の終わりの向きを準備した向きとして引き継ぐ。撃った手番なら撃った向き、撃たずに時間切れになった手番なら最後に向いた向きである。
当初は手番の終わりに準備した向きを捨てていたので、左を向いて撃っても次の手番は右向きで始まった。2026-10-03 のユーザー報告で引き継ぐように直した（TBD-44）。
再戦で対戦が変わったら、引き継いだ向きを捨てる。
ほかの参加者の手番は、サーバーがその手番の歩を 1 つ記録するまで、前に見えた向き（撃った向きか最後に向いた向き）で描き、サーバーの初めの右向きでは描かない。
そのため、ほかの参加者には、自分が動くか撃つまで、前に公開した向きで見える。相手の手番に準備した向きは、撃つまで見えない。
向きをサーバーで同期する案もあったが、`BattlePlayer` と保存する状態の形を変えることになるので、角度と同じく本人の画面だけに留めた。

- Client unit 170件。100分割/11本の主要目盛りと、斜面・左右向きの射出角を追加検証。
- PC/横向き844・667/縦向き390のシーンE2E、地形alpha。
- 2クライアントのオンライン移動・充填発射・再生・カメラ、カスタムルームの準備〜対戦〜降参〜復帰。
- キーボード操作、メニュー中の充填破棄、タッチ端末での操作とキー入力検出。
- TypeScript、通常build。現在は33章の通常入口へ統合済み。配信用buildにも含まれるが、本番デプロイとは別。

2026-10-02 時点ではmainに統合済みで、mainへのマージで本番に配置される（`deploy.yml`）。

- タッチの操作盤の並びは `apps/e2e/world-tests/touch-layout.spec.ts` で、縦持ち390×844と横持ち844×390の配置を検査する。
