# 12. キャラクターと搭乗マシン

> 2026-09-09: 新デザインの正本・色・パーツ構造・制作寸法は [16. 新デザインの制作基準](16-production-baseline-v2.md) を優先する。実装用素材は baseline-v2。旧案は履歴として区別し、新規生成の参照にしない。

## 12.1 ゲームの設定

2026-09-09 のユーザー指定により、自分のキャラクターがマシンに乗り込んで戦う設定へ変更する。
対戦は引き続き 2D のターン制砲撃。キャラクターはマシンとは別の存在としてデザインする。
降車して戦う操作、搭乗アニメーション、別のキャラクター用 HP は今回の変更には含めない。

| 対象 | 決定事項 |
|---|---|
| 本体 | 中にいるキャラクターが見えるキャノピー型 |
| キャノピー | 本体全体の形・寸法・枠・台座・座席を固定。足回りやキャラクターを替えても変えない |
| マシンの形状変更 | 足回りと武器 |
| キャラクター | 種族は将来追加可能。現在の黄色いカエル＋オレンジスカーフ＋メガネは本人専用 |
| キャラクターのカスタマイズ | メガネとスカーフは独立パーツ。種族・スキン・ペイント・互換性の制作仕様は17章 |
| 課金 | キャラクターの外見を課金要素にしたいという方針。販売方式・商品構成は未定 |

以前のタレットシェルを自由に選ぶ案は廃止する。
旧キャノピー比較案は履歴のみとする。新規制作は [original-v1](../../assets/concepts/original-v1/README.md) の採用ボードに合わせる。
キャノピーを別形状のパーツとして売り分けたり、足回りごとに形を変えたりしない。
以下で「案」「候補」「未定」と記す項目は、ユーザーが決定済みの仕様とは区別する。

## 12.2 マシンの見た目

マシンは真横から見た側面図で統一する。斜め上や斜め前からの 3/4 view、isometric の描き方は使わない。
[新デザインの真横機体](../../assets/concepts/original-v1/03-direction-refined.png)を基準に、サフランイエロー・クリーム・テラコッタの外装、太い履帯、主張のある砲身、小さな搭乗者、光沢のあるシアンのキャノピーでまとめる。
履帯・車輪は手前側の一列を見せ、奥側の履帯、車体の前面や上面を描いて奥行きを出さない。
キャノピーと武器も同じ横視点とし、砲口の正面や台座の天面が見える透視表現を避ける。
地形の傾斜や砲身の仰角は、この側面図を画面内で回転させて表現する。カメラを斜めにする意味ではない。

共通キャノピーは大きな透明のドームとし、内部の座席・キャラクター・小さい操作部が見える案にする。
マシンでは武器を主役にし、搭乗者は車体に対して小さく収める。体の下部を車体前面で隠し、搭乗していることを示す。
ガラスには半透明の淡い色と光沢を使う。周辺の枠は不透明とし、自然な目を読める透過率を保つ。
搭乗者の向きは車体の側面視点に合わせて試作し、目・白い喉・オプションパーツが読めるようにする。単体キャラクターの比較図は形を確認するために斜め向きを含めてよい。

キャノピー、台座、座席、搭乗者の位置は全足回りで共通にする。
足回りの候補は履帯・車輪・短い機械脚。これは形状を比較するための試作であり、実装する種類の確定ではない。
足回りに応じて履帯の循環・車輪の回転・脚の歩行を描き分け、マシンの位置や移動ルールは共通とする案。
本体を支える高さと接地原点を揃え、足回りの変更でキャノピーを拡縮しない。

武器はキャノピー外側の接続部に取り付ける。
標準砲だけでなく全 8 武器・左右・全仰角で、キャノピーの内部や顔を貫くように見えない配置を検証する。
顔を大きく見せることと、既存の物理上の発射位置を維持することを同時に確認する。
完成イメージ上で成立していても、回転させて顔を隠す武器は組み込み用素材として採用しない。

## 12.3 キャラクターの形

ユーザー提供の [kita.png](../../assets/concepts/pixel-pilot-v3/references/kita.png) をキャラクターの基準とする。
形状は [正面](../../assets/concepts/pixel-pilot-v3/references/front.png)、[右側面](../../assets/concepts/pixel-pilot-v3/references/right.png)、[左側面](../../assets/concepts/pixel-pilot-v3/references/left.png)、[背面](../../assets/concepts/pixel-pilot-v3/references/back.png)も参照する。
資料はユーザーが今回指定したデザイン参照であり、元画像は変更しない。
以前の小石型・頭の突起があるキャラクター案は取り下げる。
現在の素体は [baseline-v2](../../assets/workbench/baseline-v2/README.md) に16ポーズと独立オプションを制作済み。頭の接触点・自然の目を全フレームで確認する。

ドット絵でも残す特徴：

- 縦に丸い黄色の体と、頭の左右上部に張り出した白い目・黒い瞳。
- 横から見たときの前に張り出した口元と、大きな白い喉から腹へ続く色面。
- 細い腕、小さい指、開いた足先。背面は黄色で、腹の白を回り込ませない。
- 標準状態・瞬き・踏ん張り・驚き・困り顔を、元の顔の配置と姿勢の変化で表す。

**白い喉とお腹は体の色面であり、顔ではない。**
目と黒い瞳は頭の上部に張り出した本来の目の位置にのみ描く。
LOW HP、DESTROY、WRECK でも腹へ目、口、表情記号を描かない。
一部の生成プレビューにはこの誤りがあるため、制作時は元の五面資料に戻して修正する。
[14 章](./14-asset-pipeline.md) の目視レビューで全フレームを確認する。

デフォルメは小さい表示で読める範囲に限定し、別の丸い生き物へ置き換えない。
メガネを外しても自然な目が残り、スカーフを外しても喉と腹の白い形が完成している素体を作る。
ベースとなるキャラクターは決定済み。ゲーム上の正式名称と最終的なドット数・頭身は未決定。
これは初期種についての決定であり、カエルの色違いだけに限定しない。
別の種は素体・表情・搭乗姿勢・装備の接続点を個別に持ち、共通の座席原点と搭乗領域に収める。本体を種に合わせて拡縮・変形しない。
装備も種・姿勢に対応する素材を用意する。未対応の装備は選択不可とし、カエル用の素材を引き伸ばして合わせない。
搭乗中と単体表示で同じキャラクターだと分かるよう、体の色面と顔の配置を共通にする。
キャノピー内では顔に加え、上半身の色や大きな模様が見える余白を確保する。
細かい模様だけに頼った外見差は、ゲーム中に読めなければ採用しない。

## 12.4 外見カスタマイズと課金の設計境界

マシンの色とキャラクターの外見は別データ・別 palette とする。
キャラクターの外見を替えても、足回り・キャノピー・武器の形は変わらない。
キャノピーの形を固定するため、将来の衣装や装飾も共通の搭乗領域に収める。

メガネとスカーフはそれぞれ「なし」を選べる独立した装備枠とし、両方の同時装備も可能にする。
初期の見本は資料の青い丸メガネとオレンジのスカーフ。色違い・別デザインや各パーツの有料／無料は未決定。
メガネは資料と同じ頭上の位置を基準とし、キャラクター本来の目の代わりに描かない。

| 素材 | 接続と重なり |
|---|---|
| 素体 | 体・目・表情。装備の色や形を焼き込まない |
| メガネ | headAnchor に接続。後ろのつると前のレンズを必要に応じて分離 |
| スカーフ | neckAnchor に接続。背面の巻き部分と前面の結び目を分離 |

搭乗者内部は後ろ側の装備 → 素体と顔 → 前側の装備の順で合成し、全体をキャノピーより奥に置く。
左右・前後・搭乗姿勢それぞれに接続点を持たせ、瞬きや反動で装備だけがずれないようにする。
左右の見え方や結び目の非対称性は提供資料で確認し、単純反転で整合しない場合は方向別の素材を用意する。
スカーフの揺れを追加する場合も首の接続点は固定する。
全身スキンでメガネ・スカーフを重複して描かず、独立パーツとして重ねられる領域を確保する。

| 方式の候補 | 変えるもの | 未決定の内容 |
|---|---|---|
| ペイント | 体色、大きな色分けや模様 | 選べる範囲、プリセットか編集式か、無料と有料の分け方 |
| スキン | 体の表面や衣装を含む外見 | 全身一式か部位別か、輪郭変更の許容範囲 |

スキン方式とペイント方式のどちらを使うか、併用するかは今回決めない。
汎用のアバターエディターやパーツ販売 UI を先に作らず、まず搭乗した状態でカスタマイズの違いが伝わるか確かめる。
姿勢・顔の表情と外見を分離し、外見ごとに機体全体のモーションを描き直さずに済む構造にする。
マスクで表現できない衣装差は、同じ座席原点・姿勢名に対応する素材をスキン側に持たせる。

課金について今回残すのは、外見を商品にできるようマシンとは独立させる方針まで。
価格、通貨、販売方式、ショップ、購入処理、アカウント方式は未定・未実装。
外見の購入で戦闘性能が変わらない構成を提案する。性能差を販売する仕様はここでは定義しない。
販売実装時は、外見 ID と所有権を区別し、装備できるかをサーバー側の所有情報で検証する必要がある。
localStorage に保存された外見 ID だけを有料アイテムの所有証明にはしない。
現在のニックネーム・端末保存のみの仕組みからの購入者識別と復元は、課金方式を決める段階で設計する。

## 12.5 キャラクターと機体の反応

機体のモーション・武器別 VFX の詳細は [11 章](./11-sprite-animation.md) にまとめる。
搭乗者は機体と同じイベントに反応するが、表情と体の姿勢は別レイヤーで描く。

| 場面 | 搭乗者の反応案 |
|---|---|
| 待機 | 瞬き、小さい呼吸。顔が揺れすぎない |
| 移動 | 進行方向へ少し体重を掛ける。座席との位置関係は維持 |
| 発射 | 一瞬踏ん張り、反動で少し揺れて元へ戻る |
| 被弾 | 驚きと短い身震い。マシンの白フラッシュとは分ける |
| 低 HP | 不安そうな目、後方の煙へ視線、小さな汗、肩をすくめて操作部を握る。短い反応を間欠的に繰り返す。煙は顔の外へ逃がす |
| 大破 | 驚いて目を見開く→目を閉じて身をすくめ、手で頭をかばう→片目を開けて様子を見る。大破時に一度だけ再生 |
| 残骸 | 肩と頭を落とし、伏し目でしょんぼり。小さなため息の後、落胆した姿勢を維持。爆発時の驚きは繰り返さない |

旧見本の「砲塔が丸ごと飛ぶ」を搭乗者入りのキャノピーへそのまま適用しない。
今回の見本は搭乗したまま大破へ反応する案とする。脱出などの退場方式は引き続き未決定。
低 HP の不安、大破の驚き、残骸での落胆は、記号だけでなく目・肩・頭・手の姿勢で描き分ける。
メガネとスカーフは頭・首の接続点に追従させ、表情を隠したり本体の形を変えたりしない。
発射中は通常着座姿勢を保持し、車体の反動にのみ追従する。低 HP 中の被弾は一時的に驚きを優先し、発射・被弾終了後は不安な状態へ戻す。大破後は残骸用の落胆した状態に移り、通常待機へ戻さない。
一般用カエルの各スキンでも、同じ状態名に対応するリアクション素材を持たせる。

## 12.6 制作と検証

比較用のプレビューは [13 章](./13-asset-preview.md) に整理する。
これらを完成 atlas として切り抜かず、[14 章](./14-asset-pipeline.md) の原画、PNG、メタデータとして制作し直す。
最初に基準履帯、共通本体、カエル、標準砲を合成し、最小表示で顔と色を確かめる。
その後、各リアクション、オプション 4 通り、全武器、左右、坂、仰角を検証する。
一般用スキンでも搭乗領域を共通に保ち、スキンごとの装備位置と表情を制作する。
基準制作フレームは192×160 art px。追加足回り、ゲーム内の最小表示、退場方式、課金方式は未確定である。
