# 37. プラクティス

一人で遊ぶ入口を出撃準備画面の「プラクティス」に集約する。
最初の画面にはターゲットチャレンジ・自由練習・CPU戦の3つのモードだけを置く。
オンラインのロビーと招待リンクの経路は変えない。プラクティスは名前が空でも始められ、通信を必要としない。

## 37.1 画面遷移

出撃準備 → プラクティスのモード選択 → ターゲットチャレンジのステージ選択 → プレイ。
自由練習・CPU戦を選んだ場合は、それぞれのマップと装備の設定へ進む。
モード選択・ステージ選択・練習設定のヘッダーは同じ構造・文字サイズ・余白を使用する。タイトルと説明は設定言語だけで表示し、英語の補助見出しを併記しない。
色数が限られたUIで選択対象を識別しやすくするため、モード選択とステージ選択を同じ画面に混在させない。
ステージ選択・自由練習設定・CPU戦設定からはモード選択へ、チャレンジのメニュー・結果からはステージ選択へ戻る。ブラウザの戻るも同じ階層に従う。
一覧は縦持ちと横持ちに対応し、内容だけスクロールする。出撃準備へ戻るボタンは下端に固定する。
ゲーム中は現在の共通カメラ・下部HUD・長押し射撃・キーボード・タッチ操作を使用する。縦持ちと横持ちの両方に対応し、ドラッグで見回せる。全体図には残った的を黄色で表示する。
チャレンジには手番交代も時計もなく、射撃結果の再生後すぐ次を撃てる。次の射撃が可能になった時点で、カメラを自機の現在位置へ300msで戻す。動きを減らす設定では即座に戻す。クリア・失敗時は着弾結果を残して結果を表示する。

ステージ選択画面では初回は「ステージ1をはじめる」、途中からは最初の未クリア面の「つづける」を主操作にする。
クリアすると次の面を解放し、クリア済みの面はいつでも再挑戦できる。
全8面クリア後は記録への再挑戦を案内する。自由練習は解放状況によらず使える。

## 37.2 ターゲットチャレンジのルール

- 指定された弾数以内にすべての的を壊すとクリア。制限時間はない。
- 的の接地点を `(x, y)` とし、中心は `(x, y - 8)`、判定半径は3セル。支柱と黄色の同心円で表示する。
- 弾は的の判定円に当たると着弾する。爆風と的の円が接触すれば一発で壊れる。ダメージ値が0の掘削弾も有効。
- 地形が削られ、接地点の地面を失った的も破壊扱いにする。宙に残った地形そのものの崩落は計算しない。
- 弾道の衝突対象は射撃開始時の生きている的で固定し、多弾の途中で再配置しない。通常対戦の機体と同じ一斉射撃の契約を使う。
- 最後の弾も地形破壊・落下を解決してから判定する。全破壊を弾切れ・自機落下より優先する。
- 自爆によるHP減少は扱わず、戦車の場外落下は失敗にする。HPバーは表示しない。
- 移動は既存の30歩。射撃が終わるたびに回復し、角度・向き・選択武器は引き継ぐ。
- 各面に指定武器を2種類置く。プロフィールの対戦装備を上書きしない。色と音量設定は引き継ぐ。
- 風はステージごとに固定。再挑戦では地形、位置、的、弾数、角度、武器スロット、風を初期化する。

弾数無制限の自由練習と役割を分け、一発の用途を考えるパズルとして規定弾数を設ける。
最初から最少弾数を要求せず、余裕のある上限を置く。星や点数は設けず、CLEAR・使用弾数・BESTだけを記録する。

## 37.3 最初の8面

地形は400×225セルの専用長方形群。オンライン用マップや数値を変更しない。
データは `apps/client/src/practice/stages.ts`、再現できる解法は `apps/client/test/fixtures/challenge-solutions.ts` に置く。
解法は最少弾数を保証するものではない。

| 面 | 名前 | 弾数 | 風 | 学ぶこと |
|---|---|---|---|---|
| 01 | はじめの一発 | 5 | 0 | 角度と長押しパワー |
| 02 | 丘の向こう | 5 | 0 | 障害物を越す弾道 |
| 03 | まとめて一発 | 4 | 0 | 爆風で複数の的を破壊 |
| 04 | 足元が弱点 | 4 | 0 | 掘削弾と足場破壊 |
| 05 | 撃つ場所を変えよう | 5 | 0 | 屋根から移動して射線を作る |
| 06 | 風に乗せて | 5 | +6 | 一定の風の読み方 |
| 07 | 道を開け | 5 | 0 | 複数の射撃で壁を削る |
| 08 | 最後の三つ | 6 | -3 | 位置取り、武器、狙う順番 |

初期地形の根拠：05は屋根の下から直射して終わるのを避け、貫通武器を持たせない。07も貫通武器の一射で通過する構成を避け、掘削弾と標準砲で壁を段階的に削る。
これらの面の解法と、壁を一射で抜けないことをテストする。難易度の最終調整はTBD-practice-1として実際のプレイで行う。

## 37.4 プレイと結果表示

上部に面番号・名前、残りの的と弾数を表示する。下に短い操作・攻略のヒントを表示する。
着弾して地形が削られる瞬間に的の破壊を反映する。全射撃演出が終わった後に結果ダイアログを開く。
クリア後の主操作は「次のステージへ」。その下に「もう一度」「ステージ選択へ戻る」を置く。
失敗時は「もう一度」を提示する。ゲーム中の設定ボタンからも再挑戦・一覧への退出ができる。
ダイアログ中は射撃操作を止め、Tabはフォーカス移動に使う。Escはプレイ中のメニューを閉じる。結果をEscで消して操作不能な盤面に戻さない。

自由練習は現行の4つのステージ・ランダムと武器設定を維持し、設定を独立した画面に置く。終了・退出の戻り先はプラクティス一覧にする。

## 37.5 保存と境界

`fortress.practice.v1` に面IDと最少弾数を保存する。クリアした面だけが記録を持つ。
読み込み時に既知のID、正の整数、規定弾数以内を確認する。壊れたJSONは空の記録として扱う。
保存できない環境でも遊べるよう、画面内では進行を保持し、一覧に保存できないことを表示する。
ブラウザを跨ぐ同期、アカウント、途中の盤面の再開は今回の対象外。

既存の `simulateCombat` に的を衝突対象として渡す。的の中心を合わせた座標を用い、射撃中の衝突を固定する `removeDefeated=false` を使う。物理本体は変更しない。
チャレンジの進行・クリア判定はクライアント内の純関数とストアが所有し、対戦用engine・サーバー・通信プロトコルに混ぜない。


## 37.6 CPU戦

プラクティス → CPU戦 → マップ・装備設定 → 対戦。自由練習と同じ4マップ・ランダムと2枠の装備を使い、設定言語・機体色・音量を引き継ぐ。
プレイヤーは席0だけを操作し、席1の名前を「CPU」とする。CPUの手番でも下部HUDは常に席0の武器・選択スロット・射角・向き・車体の傾き・パワー・行動コストを表示する。CPU手番中も武器変更・射角調整はキーボードとタッチで行え、次の自分の手番に引き継ぐ。敵の射撃再生中も準備できる。移動と発射は自分の手番のみ有効で、敵の手番の残り移動は0とする。自分の射撃再生中・設定メニュー中・対戦終了後・手番順の演出中は準備操作も無効にする。両席を操作する自由練習は手番側の表示を維持する。先攻と配置、風、HP、移動、射撃コストによる手番、制限時間、決着は既存のローカル対戦engineに従う。
CPU戦の結果では自分の勝敗を表示し、再戦はCPU戦を維持する。退出・結果からプラクティスのモード選択へ戻れる。自由練習へ切り替えれば再び両方を操作できる。

CPUは「やさしい・ふつう・むずかしい」の3レベル。初期選択は「ふつう」。CPU戦の設定に選択と説明を置き、対戦中にもレベル名を表示する。再戦では同じレベルを引き継ぐ。装備は標準砲と三連弾。

CPUの手番は、手番順の演出が終わってから「状況を見る → 位置取り → 砲塔調整 → 構えて発射」の順に進める。
- 最初に700〜1800ms待つ。25%は留まり、それ以外は6〜18歩の移動を検討する。相手まで150セルより遠ければ接近、85セル未満なら離れ、その間では方向を選ぶ。相手機体から18セル以内への接近、障害物、段差からの落下を避ける。安全に歩けない場合はそこで止まる。
- 1歩90〜150msで、判定と同じstepOutcomeの接地点を順に表示する。移動コストは実際の歩数をengineへ渡す。
- 移動先の地形と風を使い、仰角10〜80度を10度刻み、パワー20〜100を10刻み、2武器の最大144候補を比較する。相手へのダメージを優先し、自分へのダメージを避け、同点では相手に近い着弾を選ぶ。
- 全レベルで最終照準に誤差を加える。「やさしい」は角度±14度・パワー±24、「ふつう」は±7度・±12、「むずかしい」も±2度・±4。角度10〜90度・パワー1〜100に収め、誤差を加えた後に命中を再探索しない。
- 直前の砲塔角度から1度35〜60msで調整する。最終角度の±5度以内を一度経由して狙いを直し、180〜400msの間を挟む。パワー5ごとに75msの構え時間を取り、150〜450ms待って発射する。移動距離・角度差・乱数によって手番の長さが変わる。

CPUの移動・照準はローカル専用の表示姿勢として機体と全体図に反映する。確定盤面やプレイヤーのcontrolを上書きしない。下部HUDは自分のままとし、CPUの照準線やパワーゲージは表示しない。射撃は移動先xを通常のengineへ渡し、経路と結果の照合を維持する。途中の退出・降参・再戦・手番終了で予約を解除する。

数値は「常に停止・即射撃で、命中精度も高すぎる」という実プレイ所見を受けた初期値。移動する/留まる選択、崖の回避、段階的な角度変化、待ち時間の変動、実弾道のミス、途中退出、通常決着、mismatches=0をテストする。命中率は地形・距離・武器に依存し、一定割合のミスを保証しない。自然さと難易度の最終評価はTBD-practice-2として人のプレイで調整する。

乱数と時計は呼び出し側から注入する。物理本体・サーバー・通信プロトコルは変更しない。開発用の盤面参照はDEV内に限定する。
