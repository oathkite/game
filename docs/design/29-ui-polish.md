# UI polish review 1

ユーザーと視覚調整するための第一案。他の機能開発の自動継続は一旦停止。

## 見せ方

- 遠景：彩度とコントラストを抑え、戦場と機体を前に出す。霧を通した観測窓のイメージ。
- 操作部：濃紺の読み取り面を、アイボリーの装甲と小さな銅金具で囲む。画像に文字・実メーターを焼き込まない。
- 見出しと機体展示：直接背景へ置かず、観測所の銘板と整備ベイの台座に載せる。
- ロゴ：文字・カエル・二重縁取りを保持し、小さな通気スリットと留め具だけ追加。

色：装甲 #f3dfb3、計器面 #24344a、銅 #c86b38、表示シアン #77dbe0、湿地 #657e53。
日本語は既存ゴシックを保ち、数値は太め、文字は常に面の上に置く。

## 比較と操作

地形は256pxへの縮小をやめ、より細密な素材と8texel/cellで比較する。
タンクは現在9/12=0.75倍。まずこの大きさで地形を合わせ、表示倍率のみを等倍へ切り替えられる比較を用意する。
物理サイズや当たり判定は変えない。等倍はカメラのcellを12pxにする。
カメラは上下の反応帯を24pxから64pxへ広げ、ドラッグでも任意の位置から上下移動できることを明示する。

## 検証

PC・横向き・縦向きの各シーン、文字の背景、44px操作、地形破壊後のalpha、カメラの上下移動とHUD上の誤操作を確認する。

## 第一案の実装

GPT Image 2.5 (`gpt-image-2.5-sunburst`) でロゴの微修正、コックピット枠、細密地形を作成。
`assets/workbench/ui-polish-v1/generation.json` にモデルと生成条件を記録した。
従来の採用ロゴ原本は保持し、新案をプレビューへ適用。

等倍を初期値とし、ロビーの「設定 → 機体の表示サイズ」で0.75倍へ戻して比較できる。
カメラ倍率のみの変更で、機体の物理サイズ・移動量・当たり判定は変更しない。
地形は8texel/cell、機体は12texel/cellで、従来より密度を近づけた第一案。完全に同じ密度ではない。
上下の反応帯は最大64px（狭い画面では高さの1/4）、左右は24pxを維持。
フィールド内ではホイールでも上下左右へ移動できる。Ctrl+ホイールはカメラ操作へ使わない。
承認済みの速度2.8倍、慣性1000ms、イージングは維持。

検証：camera/cameraRig unit 20件、world scenes 5件（PC・横向き2サイズ・縦向き・地形alpha）、オンライン2クライアント、TypeScript、build。
地形テストは全テクスチャ周期を含む128×128セルの全texelを検査し、透明な穴と実体の一致を保証する。
本番への組み込み・リリースは実施しない。ユーザーとの見た目の調整を優先する。
