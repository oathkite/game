# ドットテーマの4マップ（2026-09-14）

地形は画像を使わず決定論的なセルマスクで生成する。上面は明るい緑、岩肌は暗い緑と地層で描画し、背景の山並みと足場を区別する。

| マップ | 造形・狙い | オンラインのサイズ |
| --- | --- | --- |
| 稜線 | 広い裾野と中央の峰。高角度の射撃と斜面での位置取り | 350 × 225 |
| 石橋 | 厚い橋脚に支えられた薄い岩橋。下は地面がなく、落下すると敗北 | 322 × 225 |
| 段丘 | 両端の高台から段階的に下るすり鉢。高低差を使った射撃 | 350 × 225 |
| 浮島 | 高さと大きさの異なる6つの浮島。高い主島と小さな足場、下面の破壊と場外落下 | 298 × 225 |

プラクティスは既存プロトコルの400セル幅に同じ地形を中央配置する。地形を拡縮せず、オンラインと地形・スポーン間距離を共通にする。

マップ内に8箇所の安全な候補地点を定義。新規対戦では候補をシャッフルし、人数分を重複なく選ぶ。プラクティスでも左右の固定地点に限定せず、高台や中央付近から開始する。オンラインでは試合seedから決定し、復帰時には保存された座標を維持する。主砲の射程は風−10・0・10のそれぞれで、全初期位置から全相手への到達を自動検証する。地形を変えたときは `pixelMaps.test.ts` と `spawnReachability.test.ts` を再実行する。

浮島は射線検証に合わせて横幅298セル、足場の高低差45セルに調整。大小6島と厚さの違いを保ち、8人配置でも通常弾の射線を確保する。

遠景と中景は静的なドットの山並みを生成し、カメラの移動量の16%・34%で追従する。描画オブジェクトを毎フレーム生成し直さない。背景は当たり判定・破壊判定には含めない。

既存の部屋設定IDは維持し、登録マップのversionを5に更新する。保存済み対戦は保存された地形を復元し、新しい地形へ置き換えない。旧マップの定義・画像は過去資料と互換性のため残し、通常の選択肢は新しい4種類にする。
