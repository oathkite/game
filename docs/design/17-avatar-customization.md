# 17. キャラクターと本人専用アバター

2026-09-09改訂。**着脱パーツの概念を廃止する。まず本人専用の完成した外見を一体の画像として制作する。**
画像規格と確認ツールは[18章](18-avatar-portraits.md)。旧9slot・fit仕様は[19章](19-avatar-form-and-parts.md)で撤回を記録する。

## 本人専用の外見

黄色いカエル＋青いメガネ＋オレンジのスカーフはユーザー本人の大切なアバター。
本人用IDはkita-personal。一般プレイヤーの初期外見・販売・配布・未知データのfallbackに使わない。
一般用の色違いとして転用しない。元の3D資料と承認されたデザイン案を本人用参照資料として保持する。

衣装はキャラクター画像へ描き込む。メガネ・スカーフ・顔・体・手・足を着脱するslotや商品にはしない。
本人用の固定配色を維持し、ペイント・別種族・新しい衣装の選択UIは今回作らない。
将来ほかの種族を増やす余地は残すが、種族間で衣服の互換性を保証する共通rigやfitは不要。
別の外見を制作する際は、完成した一式を別IDとして扱う。

## 共通のデザイン方針

丸い胴体、短い手足、読みやすい自然の目。白い喉と腹を顔として描かない。
立ち絵は少し斜めの前方3/4、搭乗用は真横。用途に応じて別画像・別密度で描く。
メガネは頭に接し、スカーフは首を巻く状態を生成原画へ含める。
外見は機体性能・当たり判定・固定キャノピーの形に影響しない。
汎用パーツのために全種族の顔形状をそろえる制約は設けない。

## 制作範囲と状態

現在は再送3D原画を基にGPT Image 2.5で制作した本人用の一体portrait。neutral・happy・sadは各4コマのループ。
次は本人らしさと動きの方向性を確認し、必要に応じて状態間の導入や搭乗用画像を制作する。
搭乗用の現行試作は旧素材構成で動作しており、今回のportrait更新だけで置き換え済みとは扱わない。
搭乗一体スプライトへ移行する際は、次の9状態と既存の機体連動を保持する。

|状態|要件|
|---|---|
|idle|呼吸・まばたき|
|move|操縦中の小さな揺れ|
|fire|通常着座を180ms保持。のけぞらず車体の反動へ追従|
|hit|短い驚き、idleまたはlow-hpへ戻る|
|low-hp|不安・疲労。自然の目を保つ|
|fall|緊張した姿勢|
|land|450msの着地|
|destroy|驚きから脱力、600msでwreckへ|
|wreck|落胆。描画時に無彩色、車体8 artpx沈下・砲身18度下向き|

固定キャノピー内の座席・車体前面・ガラスとの重なりは機体側の描画責務として残る。
キャラクター自身のメガネ・服を別レイヤーとして合成する必要はない。

## 利用区分

本人専用画像が制作ツールから見えることと、ゲーム内で装備する権限は別。
公開時はサーバー側で認証済み本人とgrantKey=kita-personalを結び付ける。nicknameやlocalStorageでは判定しない。
一般用defaultは未決定。未制作の間は外見未設定とし、本人用へfallbackしない。
現時点で認証・購入・外見保存を実装したという意味ではない。

[カタログ例](templates/avatar-catalog.example.json)は完成外見単位の設計例。
