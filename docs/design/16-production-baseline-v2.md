# 16. 新デザインの制作基準（baseline-v2）

2026-09-09。新デザインはユーザー確認済み。メガネの浮きを修正して制作する。コンセプトの承認と、切り出した実装画像の最終承認は区別する。

## 正本

`assets/concepts/original-v1/03-direction-refined.png`、`07-weapons-refined.png`、`05-motion-board.png`、`06-effects-board.png` を新しい機体・武器・演出の正本とする。カエルだけは `assets/concepts/pixel-pilot-v3/references/` の最初の3Dモデル画像に従う。以前のタンク画像や baseline-v1 を画像生成の参照にしない。生成モデルは明示的に `gpt-image-2.5-sunburst` を指定する。

## 形状・色・構造

真横から見た丸いタンク。主役は大きな砲身。サフランイエロー、クリーム、テラコッタの外装と濃い金属色の足回りを使う。光沢のあるシアンのガラスの奥に、小さなパイロットが座る。本体とキャノピーの形状は固定し、足回り・武器・キャラクター・アクセサリーを独立交換する。

カエルは黄色い体、頭頂の突出した自然の目、白い喉と腹を持つ。白い腹に目・瞳・口を描かない。青いメガネとオレンジのスカーフは素体から分離する。メガネのフレームまたはテンプルが額に接触し、自然の目を遮らない。全ポーズで装着位置を追従させる。

## 制作フォーマット

- 出力先は `assets/workbench/baseline-v2/`。制作中は draft とし、旧パックを上書きしない。
- 共通フレームは 192×160 art px。12 art px / physics cell。
- ground は [96,144]、weaponPivot は [96,96]、muzzle は [144,96]。既存物理の4セルの高さ・砲身長を維持する。
- PNG は indexed RGBA、最大32色。透明色は index 0。半透明はガラス専用。整数倍率・nearest-neighbor で表示し、縦横比を変更しない。
- 本体は背面・前面車体・ガラス・枠の4層。描画順は足回り→背面→パイロットと装備→前面車体→ガラス→枠→武器→演出。
- 元画像、生成プロンプト、参照画像・生成画像のハッシュ、モデル名、切り出し領域、共通縮尺、出力位置、各フレームのランドマークを保存する。
- 同一アニメーションの全フレームを同じ縮尺で変換する。フレームごとの自動フィットは禁止。ソースのセル境界に不透明ピクセルがあれば切り出しを停止する。

## 必要アセット

|分類|必要な内容|
|---|---|
|本体|固定の背面・前面・ガラス・枠|
|足回り|静止、移動の位相、大破|
|カエル|idle / move / fire / hit / low-hp / fall / land / destroy / wreck|
|装備|青いメガネ、オレンジのスカーフ。頭・首のフレーム別アンカー|
|武器と砲弾|cannon / triple / multiple / drill / laser / digger / floater / stinger の各8種|
|演出|爆発、煙、マズルフラッシュ、火花、着地の埃、エネルギー等。発生→拡張→消散を連続させる|

## 検証と改善の完了条件

生成画像を見て透明背景・部品分離・横向き・余白を確認してから出力する。確認ツールでは全9状態、遷移境界、左右反転、仰角10〜90度、全武器、色変更、装備の有無、縮小表示、DPR 1/2を検証する。目の遮蔽、メガネの接触、車体による下半身の隠れ、足回りとの重なり、爆発の消散を画素と目視で確認する。

不具合は `15-animation-feedback.md` に再現条件・修正・再発防止を記録し、機械判定できるものは負例テストを追加する。同じ比較条件で新たな修正可能な矛盾が見つからず、自動検査を通過したところを今回の改善の到達点とする。自動テストで芸術的品質の上限や人間の最終承認を代替しない。未完了・未検証は明記する。


## 今回の出力実績

29アセット・74フレームを baseline-v2 に保存し、動作試験台の読込先を切り替えた。本体4層・履帯4・カエル16・オプション2・武器8・砲弾8・VFX32フレーム。パイロットの座席アンカーは [55,97]。生成素材の不均等な余白は sourceRegion とランドマークで登録し、変形せず位置を合わせた。

装備付き全16ポーズ、8武器、VFXの全コマ、PC/モバイルで比較し、セル混入、ガラス欠落、枠外の光、重複するキャノピー背面を修正。自動検査は41項目・368描画。現時点の限界は、対戦画面への統合・最小対戦倍率・一般用カエル/別足回りの未制作であり、自動合格をそれらの完成と扱わない。

最終確認記録は [quality-review.json](../../assets/workbench/baseline-v2/quality-review.json)。ブラウザ12件、主色/副色49通り、型チェック、既存テストを通過。元画像からの2回の再出力が同じパックdigestとなることも確認済み。

塗装範囲の追加指定により、黄色・ベージュの全車体面と砲身・枠をprimaryへ統一。paletteTonesで階調を保持し、透過面・金属・キャラクターは別管理する。詳細は14.10。

採掘弾は導火線つき黒色球形爆弾、レーザーはカプセルを持たない光弾へ更新。爆発・煙・土煙をタンク比率に合わせて拡大し、機体側で複数発生させる。寸法・発生タイミングの正規ルールは14章末尾、比較画像は`assets/previews/asset-lab-v2/fire.png`と`damage.png`。
