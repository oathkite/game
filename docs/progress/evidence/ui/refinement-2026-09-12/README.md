# 2026-09-12 マップ・操作・演出の改善

## 実装

- 従来8マップの輪郭に岩の凹凸を追加。谷は中央の岩橋とその下の着地面、橋は破壊後に着地できる下部の岩を追加。山・平原・段丘は岩盤内に自然なアーチを追加。浮島・洞窟・双塔の固有の構造は維持。
- オンライン2マップを version 2 に更新し、下段の足場を残したアーチを追加。初期の空洞は既存の terrainOps に含め、再接続・保存復元・リプレイにも反映。
- GPT Image 内蔵ツールで岩盤素材と透明背景の START! を生成。全マップで共通の新しい岩肌を使用。
- 移動中の段差落下に加速するアニメーションを追加。着地までは発射を無効にし、描画位置をカメラが追う。リプレイの既存の落下演出は二重に適用しない。
- 開幕は全体図、先攻、ターン順の各機体、先攻への帰還、START! の順。2人は4.5秒、8人は8.7秒。オンラインではサーバーの開始時刻に同期し、その前の移動・発射を拒否。プラクティスは描画素材と演出が終わるまでターンを開始しない。reduced motion はズーム・巡回を省略。
- タッチ操作を左の96px四方の十字キーと右の発射に統一。667×375で上48px・下112px、フィールド215px。
- 武器をマウスで選択・フォーカスした後もWASD/矢印/Spaceが動作。
- 頭上の名前の背景板と左の色バーを削除。名前は縁取り、HPは横バーで表示。
- 小さな弾を武器別に拡大。飛行中の尾と照準の点線を削除。衝突判定の大きさは維持。
- 通常の機械系武器は採用済みSuno音源のピッチを武器ごとに調整。laser/floaterは異なるWeb Audio合成の発射・着弾音を使用。新たなSuno録音を生成したものではない。

## 確認

- protocol 24、sim 107、maps 78、engine 142、client 241、server 78 tests passed。
- serverの4件のedgeテストは通常コマンドではskip。別途ローカルWranglerで8人4v4のブラウザー試験を実行し、射撃→ターン交代→決着→全員帰還まで成功。
- TypeScript: 全workspace成功。
- Chromium/Firefox/WebKitそれぞれで開幕・タッチ十字キー・武器クリック後のSpaceを確認: 9 passed。
- 8人対戦の初回累計転送量: 各6,350,329 bytes。閲覧中の5186を停止せず、preview5189 / Wrangler8798と一時的なローカル許可Originで検証。
- 最初の8人試験は検証用5189のOrigin未登録で部屋作成前に失敗。テスト起動時のALLOWED_ORIGINSを5189に合わせて再実行し成功。公開設定は変更していない。
