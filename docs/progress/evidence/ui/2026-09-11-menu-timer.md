# 設定中の残り時間

設計21.4の残り時間表示を、設定ダイアログ内にも追加。背景のHUDを読み取らずに、設定を開いたまま現在の残り時間を確認できる。

- BattleMenuStatusを練習・オンラインで共通使用。進行中の文言、残り時間、自分の手番への切り替わりを表示する。
- オンラインはHUDと同じserverNowから計算した秒数を使用。射撃の再生中は「—」。設定を開いてもサーバーは停止しない。
- 練習は既存Timerを使い、追加側のmyTurnをfalseにしてカウント音を二重に再生しない。
- 進行表示をstickyで固定し、長い設定をスクロールしても画面内に残す。role=timerは毎秒live通知せず、手番への切り替わりだけ既存のrole=statusで通知する。

検証: 変更前に設定内timerが存在せずE2Eが失敗することを確認。変更後、独立2contextのオンライン対戦で減秒→射撃再生中の空表示→次の自分の手番通知→設定を閉じて退出確認・降参まで、Chromium/Firefox/WebKit各1件成功（開発client + local Node server）。配信buildの練習設定は667×375で減秒と最下部スクロール時のtimer位置を3browserで確認。client/e2e TypeScript成功。実機検証ではない。
