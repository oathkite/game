# コックピット計器盤の調整

承認原案の濃紺の計器盤に合わせ、Desktopのパワーメーターへ独立した
くぼみ・細い枠を追加。共通SVGの帯に金属の縁を付けた。
パワー値・指針・100分割は既存の即時表示を維持する。
タッチ画面には個別のメーター枠を追加せず、コンパクトな配置を維持。

配信buildのrefinement.spec.tsをChromium/Firefox/WebKitで実行し6件成功。
開始演出中の入力無効、START後の操作、75%倍率、横向き667×375での
左十字キーと戦場高さ200px超を確認した。添付画像は最後のWebKit実行のもの。
Desktopは1440×900。角度計の金属表現（069a7d2）もこのbuildに含む。

PC/モバイルの描画確認であり、実機操作や全体の原案一致の最終承認ではない。
本番公開・main統合は未実施。
