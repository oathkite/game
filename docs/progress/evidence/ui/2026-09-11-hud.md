# HUD原案への調整

基準は`output/imagegen/game-screen-functional-v1/desktop-refined-v4.png`。その後のユーザー指定でチームは色、武器操作はQ/E。原案内のチーム図形や武器番号は復活させない。

## 比較方針

- 濃紺 #102333、金属青 #233f56、枠 #47677f、真鍮 #c7b478、文字 #f4f0deを既存素材と共用。
- 日本語フォントは既存のHiragino/Noto Sans JP。数値は既存の等幅数字を継続。
- 上部は左右の参加者と中央の時間、下部は自機・円形角度計・長いパワー・武器の順を維持。
- 目立たせるのは真鍮の角度計。その他は濃紺の計器面と控えめな枠で支える。説明文は追加しない。

## 今回の変更

1200px以上かつ高さ700px以上で上帯76px、非タッチ下帯160px。角度計を108→156px、自機カード280px、武器枠76×92pxへ拡大。メニューを上帯の下へ置き、ミニマップと重ならない配置にした。CameraPrototypeの描画領域・カメラ操作ボタンの位置も帯の高さに合わせた。

タッチ端末の下帯と小画面の寸法は従来どおり。8人対応の上部カードは既存の可変幅を維持しているが、今回のスクリーンショットは2人の練習画面であり、8人の最終見た目確認の代用にはしない。

- [変更前（1536×1024）](hud-before-2026-09-11.png)
- [変更後（1440×900）](hud-after-2026-09-11.png)

解像度・手番・カメラ位置が異なるため、画面全体の画素差で改善を判断しない。計器の寸法・配置・文字の大きさを比較した。

## 検証

client/e2e TypeScript成功。scenes.spec.tsの8件成功（1440×900、844×390、667×375、390×844で遷移・操作、武器内SVGの寸法、地形alphaと区画更新）。一時的な既存サーバー使用configで実行し、終了後configを削除。

## 残る差

- 岩盤の形状・草の密度と原案の細かな崖の構成は異なる。
- 機体の搭乗パイロットとポートレートの造形差。
- 8人での最終HUD比較、各シーンとの素材統一。
- 上記を含めた最終デザイン承認は未完。
