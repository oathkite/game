# 岩盤の表示サイズ

承認済みゲーム画面原案に比べ、岩の一つ一つがタンクと同程度に大きく見えていた。既存岩盤v4画像は維持し、繰り返しタイルの高さを256から128描画pixelへ変更。縦横比は維持する。草・タンク・カメラ・物理mask・GPU区画サイズは変更しない。追加画像の生成や配信量の増加はない。

[変更後の1440×900ゲーム画面](./terrain-smaller-rocks.png)

3browserで地形の1:1/3:1縦横比、alphaと破壊maskの一致、区画境界のパターン連続、変更区画だけのGPU更新、草の境界更新を9件確認（8.5秒）。client/e2e typecheck成功。テストの繰り返し幅の期待値を新しい128pxへ更新した。

これは開発版での検証。全UIの最終採用、実機のドット密度・性能評価を完了扱いにはしない。
