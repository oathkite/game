# 開始前のチーム人数表示

設計22.1では人数差のある現在の編成を開始前に全員へ明示する。従来の「人数差のある編成でも開始できます」という一般説明に加え、部屋snapshotからチーム別人数を表示する。

- チーム色・色名・人数を列挙。空チームは省略し、未配置を別計数する。
- 2つ以上のチームの人数が異なると「人数差あり」。同数編成やFFAでは表示しない。
- 編成の自動補正や開始制限は追加しない。team移動・入退室で各clientのsnapshotに追従する。
- 日英対応。小さい横画面ではパネル内をスクロールでき、準備ボタンは画面内に維持する。

検証: unit 3件（非対称・同数/FFA・未配置/組み替え）、翻訳coverage、client/e2e TypeScript成功。独立3contextで1対2→3人FFA→1名退出の表示を全員で確認し、Chromium/Firefox/WebKit各1件成功（local Node serverと開発client）。667×375の準備ボタン位置も確認。[画面](room-team-counts.png)。実機・対戦バランスの評価ではない。
