# ブラウザーの戻る操作

2026-09-11。設計21.7と実装を照合し、画面内の戻るボタンしか扱っていなかった経路を追加。

- タイトル以外で同一documentの履歴を1件だけ保持。戻るをWorldScenesの既存遷移へ渡す。設定→ロビー→タイトルの親画面へ戻り、タイトルではガードを外して元のサイトへ戻れる。
- 終了済み試合を履歴から再開するscene履歴は保存しない。ブラウザーの進む操作で過去の試合を再演する機能ではない。
- 練習・オンライン戦闘では長押し・移動・パンを取り消し、退出確認を表示。キャンセルまたはEscapeで継続。オンラインでは確認中もサーバーの対戦は進むと説明。
- 承認時は既存の退出処理へ接続し、room.leaveを送信。サーバーは参加者を降参扱いにし、端末の復帰tokenを削除。観戦者・終了後は降参説明を出さず退出の説明にする。
- 待機部屋は戻るでroom.leaveを送り席を解放。招待による直接入室でもガードを用意する。
- 日英の確認文を追加。通常のタブ閉じ・アドレス入力・複数履歴を飛ばす移動を阻止するものではない。そうした切断は既存の再接続猶予で扱う。

- local Node room server + 開発client: 独立2contextで招待から対戦→戻る取消でtoken保持→承認でtoken削除・相手勝利、待機中の退出→相手の人数減少を確認。3browser各2件、合計6件成功。
- 開発StrictModeの再読込をChromiumで別途1件成功。effect二重実行で履歴を二重に戻さない。
- client unit 227件、client/e2e TypeScript成功。
