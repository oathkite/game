# 苔の谷 v3・8人対戦

配信buildとlocal SQLite DO、8独立contextの4v4。
入室・準備・実射撃共有・4名降参・全員の成績一致・帰還待機・全員の部屋復帰を確認。
射撃のみの自然決着、実機性能、実Cloudflare容量の検証ではない。

- 中断前の実行ログでChromium 54.0秒、Firefox 24.9秒の成功を確認。
  初回対戦までのencoded transfer最大はそれぞれ6,449,786B、6,420,022B。
- WebKitは再実行。最初は180秒の全体上限で失敗し、traceを調べると
  射撃・勝敗・成績検証後の、順番に処理していた帰還操作まで進んでいた。
- 7人の帰還要求と待機状態の確認を並行化。最後の1人の要求までは
  7人全員が帰還待ちであることを引き続き検証する。
- 同じ180秒上限でWebKit成功（2.4分）。各contextの転送量7,103,646B。
  全員の部屋コード・8人の参加者・準備ボタンを確認した。

WebKitのbuild対象は7377233＋帰還試験の並行化。
試験中に編集した角度計の見た目（069a7d2）は本スクリーンショットには含まない。
角度計は別途4 unit・client型チェックと5186の実画面で確認した。
