# 初回練習の短い案内

設計20.3の「風→角度→長押し発射」を、出発の準備画面の折りたたみ案内として実装した。練習を強制せず、案内を閉じずに練習開始ボタンを押しても進める。対戦画面には説明を追加しない。

- 初回は開いた状態。一度閉じるか練習へ進むと次回から折りたたむ。概要を選べばいつでも再表示できる。
- キーボードはW/S・上下キーとSpace、タッチは＋/−と発射ボタンを案内する。風は葉の流れ、角度は円形メーターで確認する。
- 日英対応。保存が拒否されても現在の訪問中は選択を保持し、操作や練習への遷移を妨げない。
- メニュー内で内容をスクロールでき、出撃ボタンは外側に保持。既存の濃紺パネルと書体を使用。

[390×844・英語・タッチの表示](practice-guide-touch.png)。実機の操作検証とは別。
