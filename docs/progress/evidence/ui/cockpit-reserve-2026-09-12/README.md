# 計器盤と移動残量の仕上げ

承認済み原案の濃紺パネル・金属縁・青い移動残量表示を参照した。帯の高さ、パワーメーターの幅、カメラ倍率は維持。

- コックピットの共通SVGへ段差のある金属縁と留め具を追加。
- 残り移動は数字と3区画の青いメーターで表示。1区画10歩で部分充填し、30→29など1歩単位を保持。ゲームルールは変更しない。
- モバイルで隠れていた残量を円形角度計の下へ表示。十字キー・発射ボタン・戦場の高さは維持。
- Desktopの156px角度計は実画面で下端904pxとなり、900px viewportから4px切れていた。直径144pxへ調整し、円全体を表示。
- 置き換えで不要になったsmall用のCSS指定は除去。

## 検証と実画面

`production.config.ts refinement.spec.ts` の6件が46.9秒で成功（Chromium / Firefox / WebKit、Desktop1440×900とtouch667×375）。
開幕中の入力遮断、75%倍率、角度計の画面内収容、残量30→29、モバイルの戦場高さ200px超を確認。
角度計の画面内収容は修正前904pxで失敗し、修正後に成功した。
残量計の0/17/30・パワー100分割・角度変換のunit計7件、client/e2e型チェック、diff checkも成功。
