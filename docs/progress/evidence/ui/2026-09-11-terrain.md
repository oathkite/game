# 岩盤素材v4

承認原案と実画面を比較し、大きな柱状岩が均一に反復するv3から、大小の岩と割れ目が混ざるv4を内蔵画像生成で作成した。API/CLI生成は使っていない。原本・参照・生成方針をworkbenchに保持し、旧v3も残す。

原本は2172×724。runtimeは同寸法の可逆WebPでRGBA完全一致。草・地形mask・衝突判定・テクスチャ解像度の処理は変更していない。上下左右の厳密な画素一致を達成した素材ではなく、完全なseamlessを保証しない。

[ゲーム内表示](terrain-v4-in-game.png)。旧表示はhud-after-2026-09-11.pngを参照。細かな岩の密度は近づいたが、原案の崖・洞窟・草の構図全体が一致したという意味ではない。搭乗パイロットの形状差と最終アート承認は残る。

検証：encode-world.pyの生成・check（13点RGBA/誤差条件）、assets:check、terrain alpha・1:1/3:1比率・区画更新と1440px画面遷移の4ブラウザテストが成功。

production rootはChromium/Firefox/WebKitで各1件成功。初期タイトル最大1,860,696 B、初回練習まで累計最大7,831,011 Bで2MB/8MB以内。残り2エンジンの累計は7,800,701 Bと7,801,202 B。実機や互換音声形式の転送量の証明とは別。
