# 画像地形の試作 — 苔むす岩橋

プラクティスのマップを、GPT Imageで地形全体を描いた岩橋へ変更。既存マップは維持。

- 元画像のalphaによる輪郭をそのまま表示し、岩肌を繰り返し貼らない。
- 固定の400×225衝突マスクをalphaから事前生成。草や短い根による孤立した細い帯を除き、安定した初期位置を選択。
- 爆発は元画像の解像度で円形に削り、縁に暗い断面を付ける。物理マスクも同じ爆発位置・半径で削る。物理の輪郭はセル単位なので画像との誤差は概ね1セル以内で、連続形状の物理エンジンへの変更ではない。
- 上の橋を壊したとき、下の独立した岩へ着地できる。
- 描画は1536px以下のcanvasに分割。未破壊部分のalphaを量子化しない。衝突マスクだけから復元するfallbackでは削れた箇所はセル形状になる。オンライン移行時には破壊履歴を使った再描画の追加が必要。
