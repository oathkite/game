# KEROPOD 公開前の判断と外部検証

実装の続行に必要のない判断は保留し、未回答を承認として扱わない。本番公開・main統合は別指示。

## ユーザーの判断が必要

| 項目 | 決める内容 | 現在の状態 |
| --- | --- | --- |
| 最終アート | 原案と実画面の比較後、ロゴ・地形・HUD・各シーン・一般用機体素材の採用 | 実装側の調整中。runtimeのpendingは人間承認に書き換えない |
| 公開の段階 | 招待alphaの参加範囲、最初の地域、募集方法 | 世界公開を目標に実装。公開日は未設定 |
| 運営情報 | 運営主体、問い合わせ・削除依頼窓口、対象地域/年齢 | 規約・privacyの内容確定に必要 |
| 通報対応 | 確認担当、対応時間、処分基準、異議申立て窓口 | 通報受付と7日保持は実装済み。人員・判断基準は未確定 |
| 費用 | 検証用stageと運用の月額上限、通知先、上限到達時の停止方針 | ローカル負荷試験で実クラウド費用を保証しない |
| 認証 | 任意ログインの提供時期・方式、本人専用アバターの本人確認とgrant付与 | 現行対戦は匿名session。本人専用外見を一般用fallbackにしない |
| 実機 | 代表iPhone/Androidの型番・OS、利用可能なテスト端末 | 自動ブラウザエンジン試験は実機検証を代替しない |

## 実環境で必要な検証

- 対象端末で8機・全武器・最大破壊を含む10分描画、frame p95・入力遅延・温度。
- RTT250msで相手移動表示p95、ネットワーク復帰から部屋復帰p95。
- stageの実Durable Objectsで同時100部屋とDirectory負荷、CPU・保存量・費用。次の1,000部屋は別測定。
- 複数地域から入室→射撃→結果を完走し、エラー監視・費用通知・ロールバックを確認。
- 人間が操作する8人実戦で、編成・風・地形の体感バランスを確認。射撃のみの自動4v4完走は3browserで追加済み（evidence/natural-match）。人間の体感評価は別途必要。

機能・ローカル試験・見た目の残件は[最終照合](final-audit-2026-09-10.md)と[進捗](completion-2026-09-10.md)を参照。
