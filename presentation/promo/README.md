# TANK SHOOT 紹介動画

ゲームを紹介する 48 秒の動画と、その制作一式。
説明のテキストは入れず、ゲームの画面と音だけで見せる。
動画はアーティファクト「TANK SHOOT 紹介動画」（https://claude.ai/artifact/3DFUbiRo3YDtrVra6ZSB4c）に置き、リポジトリには入れていない。

- 今の版：`tank-shoot-promo-20261009.mp4`（1920×1080、60fps、約 11 MB）
- 前の版：`tank-shoot-promo-20261001.mp4`（同じアーティファクトに残す。`presentation/video/prepare-assets.sh` がこのファイルからプレゼン動画の素材を切り出すため）

10 月 1 日の版の制作スクリプトは残っていなかったので、10 月 9 日の版でここに作り直した。

## 構成

BGM はゲームの主題曲「稜線」（126 BPM、1 小節 1.905 秒、24 小節）。
場面は拍の頭で切り替え、着弾を小節や拍の頭に置く。
割り付けは `edit.mjs` の `CUTS` にある。

| 小節 | 場面 |
|---|---|
| 1–4 | 格納庫の機体の色、砲塔、足回りが拍ごとに入れ替わる。後半の 2 小節は寄せて、入れ替わりを速める |
| 5 | タイトル |
| 6–9 | 開幕の見回し、溜め、山越しの弾道、9 小節目の頭（B の頭のシンバル）で着弾 |
| 10 | 掘削弾で山頂をえぐる |
| 11–12 | 逆関節、浮遊、多脚、大玉の足回りで歩く |
| 13–14 | 8 種の武器を 1 拍ずつ（FX ラボ） |
| 15–17 | ダブルシュートの 2 発、テレポート |
| 18–19 | 着弾と撃破を 1/8 の速さで（FX ラボ。曲が沈む C の区間） |
| 20 | スマートフォンの縦持ちと横持ち |
| 21–22 | 最後の 1 発で撃破（D の盛り上がり） |
| 23–24 | 稜線、石橋、段丘、浮島の見回し |
| 25– | タイトルの「はじめる」の位置に公開の URL を打ち、曲の頭の解決で消える |

## 作り方

すべて、今のゲームを Playwright の偽の時計で 1/60 秒ずつ進めて 1 コマずつ撮った実際の画面である。
コマの補間や描き足しはしていない。

- `capture.mjs`：場面（`scenes.mjs`）を撮って `out/scenes/<場面>.mp4` に書く。あわせて、鳴った効果音の名前と時刻、目印のコマ、カメラの中心と機体の位置を `out/scenes/<場面>.sfx.json` に書く
- `edit.mjs`：割り付けに従って場面を切り出し、`out/video.mp4` につなぐ。切り出しの基準は目印か鳴った音のコマなので、撮り直してコマがずれても着弾は拍に乗ったままになる。機体へ寄せるときは、記録したカメラの中心と機体の位置から画面上の位置を出し（1 セル 8 px）、整数倍に切り出して最近傍で拡大する
- `audio.mjs`：BGM の上に効果音を重ねて `out/audio.wav` に書く。ブラウザの OfflineAudioContext で、ゲームの `sfx.ts` と `soundRecipes.ts` をそのまま使い、出力経路（圧縮器、残響、着弾で BGM を下げる量）も `audio.ts` と同じにする
- `master.sh`：映像と音を合わせ、音を -16 LUFS にそろえて配信用に縮める

client のソースは変えていない。撮るときに、Vite が配る 2 つのモジュールだけを書き換える。

- `src/app/audio.ts`：`playSound` の頭で、名前と時刻を `window.__promoSfx` に残す
- `src/dev/fxLabScene.ts`：FX ラボの 2 台の名札を P1 と P2 にし、機体を対戦の場面と同じ見た目にする

## 作り直す手順

リポジトリのルートで実行する。ffmpeg と Node.js と、`apps/e2e` の依存（Playwright の Chromium）が要る。

1. client の dev server を起こす：`pnpm --filter @game/client dev --host 127.0.0.1 --port 5173 --strictPort`（別のポートなら `GAME_URL` に渡す）
2. 場面を撮る：`node presentation/promo/capture.mjs <場面...>`。場面の一覧は引数なしで出る。全部で数分かかる。並べて回してもよい
3. つなぐ：`node presentation/promo/edit.mjs`
4. 音を作る：`node presentation/promo/audio.mjs`（dev server を使う）
5. 書き出す：`presentation/promo/master.sh`（`out/tank-shoot-promo-20261009.mp4`）

途中の絵は `ffmpeg -i presentation/promo/out/video.mp4 -vf "fps=1/0.952381,scale=320:-1,tile=8x7" -frames:v 1 sheet.png` で半拍ごとに並べて確かめられる。

## 注意

- どの場面でも、開始の合図（START!）、手番の表示（あなたのターン）、モードの名前（自由練習）は CSS で隠して撮る。動画に説明の文字を入れないためである。残る文字はゲームの HUD（ゲージの目盛りと数値、残り時間、手番の欄、P1 と P2 の名札、ダメージの数値、スマートフォンの「発射」ボタン）と、締めの URL である
- 10 月 1 日の版にあった「オンライン対戦」の 8 台の図は入れていない。実際の対戦を撮るには部屋のサーバー（v2 Room API）を起こし、複数のブラウザを偽の時計でそろえる必要があり、今回の撮り方の外にある
- 撮影は GPU（Metal）で描く新しいヘッドレスの Chromium で開く。旧ヘッドレスのソフトウェア描画では、戦場の右下が黒く抜ける
- HUD を出さない場面は、画面を 1920×1240 で開いて上の 1920×1080 だけを撮る。戦場の高さはゲームが「画面の高さ − 操作盤」で決めるので、CSS では広げられない
- 手番の始まりの「あなたのターン」の間は操作盤が無効で、キーが捨てられる。照準と発射は、武器のボタンが押せるようになってから行う
- スマートフォンの場面は、キーを使うとタッチの操作盤が引っ込むので、十字キーと発射のボタンを押して撃つ
- 「スマートフォンの縦持ちと横持ち」は、2 つの画面を暗い地に並べた合成である。2 台は同じ対戦を別々に撮っている
