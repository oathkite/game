# 全ビジュアルの再制作 / GPT Image 2.5

この指示書は途中案。最新の参照範囲と初期案は [original-v1](../original-v1/README.md) を正とする。

2026-09-09 のユーザー指示により、搭乗者、タンク、足回り、武器、砲弾、VFX、全モーションを作り直す。
キャラクター単体だけの作り直しではない。

## 共通条件

- 初期カエルはユーザー提供の原写真を正とする。旧生成スプライトの誤った解釈を引き継がない。
- 白い喉・お腹は体の模様。頭上の自然な目、閉じた小さな口と区別する。
- メガネとスカーフは別素材。別のキャラクター種を後から増やせる設計を維持する。
- 車体は真横。本体と光沢のあるキャノピーは固定。足回りと武器が交換部分。
- 搭乗者は小さめ、武器が主役。履帯が車体を支え、腰から下は車体の奥へ隠れる。
- ガラスはアルファを持つ独立素材。顔を不透明な反射で隠さない。
- 生成は `gpt-image-2.5-sunburst` を明示指定。プロンプト、参照、モデル、結果を保存する。

## 制作単位

| 順序 | 制作内容 | 納品と検査 |
|---|---|---|
| 1 | カエルの正面・真横・背面、素体とオプション | 解剖学、同一体格、画素密度、着脱を比較 |
| 2 | 固定本体、ガラス、履帯、8武器、合成時の比率 | 本体前後とガラスを分離。左右、全仰角、反動時に目が見える |
| 3 | 8砲弾、発射光、爆発、煙、火花、破片、着地煙 | 原点固定、連続コマ共通倍率、拡大と消散、隣コマ混入なし |
| 4 | 待機・移動・発射・被弾・低HP・落下・着地・大破・残骸 | 搭乗者の反応と機体の動きの同期。装備は全コマ追従 |
| 5 | 新 pack へ書き出してガレージで比較 | 形式・レイヤー・ループ・全コマ境界・DPR・実寸を再検査 |

既存 baseline-v1 は比較と回帰テスト用。新デザインの代用として完成扱いにしない。
デザインボードは概念確認用であり、そのまま atlas として読み込まない。
制作規約は [14章](../../../docs/design/14-asset-pipeline.md)、再発防止は [15章](../../../docs/design/15-animation-feedback.md) を適用する。

## 生成状況

最初のキャラクター案を Image API の edit、model `gpt-image-2.5-sunburst`、quality high、1536x1024 で要求した。
API から `429 / credit_balance_exhausted` が返り、画像出力はまだない。
API クレジット追加後に同じ明示モデル指定で再開する。モデルの黙示的な置き換えは行わない。
API キーは Git 除外済みの `.env.imagegen.local` に置き、画像・プロンプト・レポートへ含めない。
