# 新しいビジュアル初期案

最新のユーザー指定：カエルだけは最初の3Dモデル資料を参照する。
タンク、足回り、武器、砲弾、演出は以前の機体案を参照せず、初期案から新規制作する。
今回生成した新しい全体案は、シリーズ内の修正・展開で配色と造形を揃える参照として使う。

## 維持するゲーム要件

- 2Dドット絵、完全な真横のマシン。
- 本体とキャノピーは固定。足回りと武器を交換できる。
- 搭乗者は小さめ、砲台が主役。搭乗者の下半身は車体前面の奥へ隠れる。
- ガラスは半透明の色面と光沢を持ち、自然な目を隠さない。
- カエルのメガネとスカーフは独立したオプションパーツ。
- カエルの白い喉とお腹を顔や口として扱わない。

## 生成

モデルは `gpt-image-2.5-sunburst` を明示指定する。
添付参照はカエルの3Dモデル写真のみで、その参照用途はカエルの形状・配色・装備に限定する。
旧タンクや旧スプライトは入力しない。
全体案の制作指示は [02-frog-and-new-world.txt](./prompts/02-frog-and-new-world.txt)。各修正と展開の指示も prompts に保存する。
01-initial-direction.txt は「元資料を使わない」という指示の時点で作った不採用の中間指示で、再利用しない。
pixel-pilot-v4 の旧生成依頼も再制作の基準にしない。

デザインボードは初期案の比較用。完成したゲーム用atlasとは区別する。
量産時は全コマの共通倍率、等間隔セル、透明な余白、接続点、レイヤー、原点を検査する。

## 完成した初期案

すべて Image API の edit で `gpt-image-2.5-sunburst`、quality high、1536x1024 を明示指定して生成した。
キーの設定後に発生したローカル依存関係の不整合は、隔離した uv 環境と aiohttp / Brotli の更新で解消した。

02 と 04 の画像は修正前の比較用で、採用候補は 03 と 07。
素体の背面にスカーフが入る問題と、素体側面のメガネ混入を修正した。
砲口が楕円に見える投影も追加編集で修正した。
モーションは姿勢を比較するストーリーボードであり、全フレームの連続性やリグの一致を保証するatlasではない。
表示サイトの baseline-v1 は比較用の旧素材。新しい画像を旧素材へ自動で上書きしていない。
次の制作ではボードをそのままセル分割せず、新デザインから前後レイヤーと連続フレームを制作する。
生成条件とファイルの SHA-256 は [generation.json](./generation.json) に記録する。
